# 3人対戦じゃんけん（ポイント制）

あなた・相手1・相手2の3人でじゃんけんをして、先に目標ポイントを取った人が優勝するブラウザゲームです。

## あそびかた

1. `index.html` をブラウザで開きます
2. 「目標」で何ポイント先取にするか選びます（3／5／7ポイント）
3. 「グー」「チョキ」「パー」のボタンから手を選びます
4. 「じゃん・けん・ぽん！」の後に3人の手が出て、ポイントが増えたり減ったりします
5. 誰かが目標ポイントに届いたらゲーム終了です。ランキングが出るので「もう一度あそぶ」で再挑戦できます

## ルール

| 結果 | ポイント |
| --- | --- |
| 勝ち | +1 |
| ひとり勝ち（2人に勝つ） | +2 |
| 負け | -1 |
| あいこ | ±0 |

- 3人とも同じ手か、3人ともバラバラの手ならあいこです
- 3人ともポイントを持っていて、相手もポイントが増えたり減ったりします
- 目標ポイントに同時に届いた場合は、ポイントの高い人が優勝です。同点なら全員優勝になります

## 画面の見かた

- **カードのポイント表示**：今のポイントです。マイナスになると赤字になります
- **ゲージ**：目標ポイントまでどれくらいかを表します
- **+1 / -1**：勝ち負けが決まると、カードの上に浮かんで出ます
- **第◯回戦**：何回目の勝負かを表します
- **🔥◯連勝中！**：あなたが2回以上続けて勝つと出ます
- **履歴**：直近8回の勝負（3人の手と勝った人）が新しい順に出ます

## ポイントの調整

`js/test.js` の先頭にある数字を変えると、ルールを変えられます。

```js
var WIN_POINT = 1;    // 勝ったら +1
var SOLO_BONUS = 2;   // ひとり勝ち（2人に勝つ）なら +2
var LOSE_POINT = -1;  // 負けたら -1
var goal = 3;         // 目標ポイント（最初の値）
```

目標ポイントの選択肢は `index.html` の `<select class="goal-select">` の中にある `<option>` を増やしたり変えたりすると変更できます。

## 主な関数（js/test.js）

| 関数 | やっていること |
| --- | --- |
| `janken(me)` | ボタンを押したときに呼ばれます。相手の手をランダムに決めて「じゃん・けん・ぽん」を表示します |
| `show(me, cpu1, cpu2)` | 3人の手を見せて勝ち負けを判定し、ポイントを計算します |
| `loseToOf(hand)` | その手が負ける手を返します（グー→パー など） |
| `updatePoints()` | ポイント表示・ゲージ・回戦数・連勝数を更新します |
| `floatPoint(i, value)` | 「+1」「-1」をカードの上に浮かせます |
| `addLog(text)` | 履歴に1行追加します |
| `checkGameOver()` | 目標ポイントに届いた人がいるか調べます |
| `showResult(champions)` | 結果画面（ランキング）を表示します |
| `resetGame()` | ゲームを最初の状態に戻します |

## 使っているもの
